System Design

What's Under the Hood

A complete embedded stack — from hardware SPI bus management to HTTPS API calls on a microcontroller with 320KB of SRAM.

📡

Dual-API Architecture

YouVersion provides the curated daily verse reference. The Scripture API resolves it into readable text. Two HTTPS calls, one verse, zero configuration needed after setup.

HTTPS · SSL · JSON
🔌

Shared SPI Bus

The ILI9341 display and SD card reader share one SPI bus with dedicated chip select lines. Images are loaded into a RAM framebuffer before the SD card is unmounted — eliminating bus conflicts.

SPI · CS Management
🖼️

RGB565 Framebuffer

BMP images are decoded manually from raw bytes, converted to RGB565 format, and pushed to the display in horizontal strips — bypassing displayio entirely for reliable, full-colour output.

BMP Parsing · 16-bit Colour
💾

Memory Management

The ESP32-S2 has 320KB SRAM plus 2MB PSRAM. Explicit gc.collect() calls, response object cleanup, and careful buffer sizing keep the device stable across long uptime periods.

CircuitPython · gc
🔁

Resilient Networking

WiFi reconnects with exponential backoff. API calls retry up to three times with increasing delays. Three consecutive failures trigger a full WiFi reconnect cycle before falling back to a soft reboot.

Retry Logic · supervisor.reload
🌅

PWM Backlight

The display backlight is off during boot and loading, then fades in smoothly once content is ready. The slideshow fades out and back in between images for a polished visual transition.

PWM · UX Polish

API Design

Why Two APIs?

YouVersion's developer API returns the verse reference for each calendar day — not the text. A second call to the Scripture API resolves it. Here's the full request chain:

1

Device boots and connects to WiFi

Exponential backoff retry up to 5 attempts. On failure, the device waits and retries rather than crashing.

2

GET YouVersion Verse of the Day

api.youversion.com/v1/verse_of_the_days/{day_of_year}

Returns a passage identifier — e.g. JHN.3.16 — for today's curated verse.

3

GET verse text from Scripture API

rest.api.bible/v1/bibles/{bible_id}/verses/JHN.3.16

Returns plain text content and a human-readable reference string.

4

Render and display

Text is word-wrapped to fit the screen, drawn in white on a navy background, with the reference in gold. The display refreshes once per day at midnight.

Implementation

Key Design Decisions

Loading BMP images from an SD card onto a shared SPI bus is the core technical challenge of this project. The solution: decode the BMP into RAM first, then render. 

# The naive approach — causes a bus conflict on shared SPI:
# bitmap = displayio.OnDiskBitmap(f)  ← reads SD during display refresh

# The correct approach — separate load from render:

def load_bmp_to_rgb565_framebuffer(path, rotation=0):
    """Decode a 24-bit BMP into an RGB565 bytearray in RAM."""
    gc.collect()

    with open(path, "rb") as f:
        header   = f.read(54)
        bmp_w    = read_le32(header, 18)
        bmp_h    = read_le32(header, 22)
        fb       = bytearray(DISPLAY_WIDTH * DISPLAY_HEIGHT * 2)
        row_size = ((bmp_w * 3 + 3) // 4) * 4

        for row in range(bmp_h):
            f.seek(pixel_offset + row * row_size)
            f.readinto(row_buf)

            for x in range(bmp_w):
                b, g, r  = row_buf[x*3], row_buf[x*3+1], row_buf[x*3+2]
                dx, dy   = map_rotated_pixel(x, y, bmp_w, bmp_h, rotation)
                idx      = (dy * DISPLAY_WIDTH + dx) * 2
                fb[idx], fb[idx+1] = rgb888_to_rgb565_bytes(r, g, b)

    return fb  # SD card can now be safely unmounted


def show_image(path):
    new_fb = load_bmp_to_rgb565_framebuffer(path, IMAGE_ROTATION)
    unmount_sd()          # release SPI bus
    fade_out()
    draw_framebuffer(new_fb)  # push directly to ILI9341
    fade_in()

Takeaways

What This Project Taught Me

SPI BUS ARBITRATION

Two devices on one bus need careful sequencing. The solution here — load to RAM, release bus, render — is a pattern applicable to any shared-resource embedded design.

MEMORY ON MICROCONTROLLERS

With 320KB of SRAM, every allocation matters. Explicit gc.collect(), closing HTTP responses immediately, and avoiding string concatenation all make a measurable difference.

RESILIENT NETWORKING

WiFi on embedded devices is never guaranteed. Exponential backoff, connection pooling, and supervisor.reload() as a last resort made this device reliable in daily use.

API DESIGN CONSTRAINTS

YouVersion's API returns a reference, not text — requiring a second API call. Understanding this separation led to a cleaner two-API architecture than a single monolithic call would have.

DISPLAY RENDERING

Bypassing displayio's OnDiskBitmap and writing raw RGB565 data directly to the ILI9341 via SPI gave full colour fidelity and complete control over the render pipeline.

UX ON EMBEDDED

Small touches matter — a fade-in backlight, a status message during boot, gold text for the reference. These details are what separates a working prototype from a finished product.
